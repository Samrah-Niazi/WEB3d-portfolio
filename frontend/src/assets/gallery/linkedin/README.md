# LinkedIn pictures for the gallery

Save the pictures from your LinkedIn posts in this folder (.jpg, .png or .webp). They appear in the
gallery under "Achievements" automatically; there is nothing to register.

The file name decides which post the picture links to:

| File name starts with | Links to |
|---|---|
| `runner-up` or `gamecon` | the GAMECON'26 runner-up post |
| `fydp`, `winner` or `taleem` | the Best FYDP post |
| anything else | your LinkedIn profile |

Example: `runner-up-1.jpg`, `fydp-winner-2.png`. The file name (without the extension) is used as the caption,
so descriptive names such as `runner-up-on-stage.jpg` give better descriptions for screen readers.
Please keep each picture under about 1 MB.
