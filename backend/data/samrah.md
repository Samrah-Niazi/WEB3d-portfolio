## Project: The Unbroken Oath
@section projects
The Unbroken Oath is a Unity 3D first-person tactical rescue shooter (Operation Sun Temple). Three members of the player's squad are held in separate rooms of a temple, and the player, as the last warrior free, fights through enemy soldiers to rescue them, with the game moving from a bright morning into a night storm with rain, fog and lightning. It has rescue, victory and death cutscenes, three weapons and cookable grenades, a minimap and full map, an operator voice assistant with subtitles, a hand-held torch, and an animated main menu. The characters are modeled with the faces of the developer and her team. It won runner-up at GAMECON'26. Source code: github.com/Samrah-Niazi/The-Unbroken-Oath. Play it on itch.io: samrah-niazi.itch.io/the-unbroken-oath.

## Project: The Abduction
@section projects
The Abduction is a Unity 3D third-person horror-adventure escape game. A young boy is kidnapped and trapped in a dark abandoned asylum, and the player explores rooms and floors, solves linked clues and riddles, collects items, and survives guards and air patrols while searching for the final key. It has enemy AI with sight and noise detection and patrol logic, a clue system, combat and survival mechanics, and atmospheric horror lighting. Source code: github.com/Samrah-Niazi/The-Abduction. Play it on itch.io: samrah-niazi.itch.io/the-abduction.

## Project: VR Escape Room
@section projects
VR Escape Room is a Unity 3D VR escape room for Meta Quest, built with the XR Interaction Toolkit. It has hand/controller interaction, teleportation, object grabbing, and socket-based puzzle UI. The source code is on GitHub: github.com/Samrah-Niazi/Escape_VR_Room.

## Project: Spikes Rush
@section projects
Spikes Rush is an endless runner built in Unreal Engine 5.7 entirely with Blueprints, set inside the human bloodstream. The player is a germ running down a blood capillary, collecting bacteria instead of coins, grabbing a magnet power-up, and dodging syringes and white blood cells. It has a saved high score, a game-over summary, and a curved-world material that bends the track into the distance. Source code: github.com/Samrah-Niazi/Spikes-Rush.

## Project: Warp: Fractured Reality
@section projects
Warp: Fractured Reality is a two-player local split-screen co-op sci-fi runner made in Unity 6. Two scientists are trapped in a collapsing warp tunnel and must dodge barriers and rewinding hazards and use warp pickups, which disable the hurdles for about six seconds, to escape. Both players must reach the end to win, so teamwork matters more than speed. It is a re-themed version of the game-jam project The Masked Regime. Source code: github.com/Samrah-Niazi/Warp-Fractured-Reality. Play it on itch.io: samrah-niazi.itch.io/warp-fractured-reality.

## Project: Super Jump
@section projects
Super Jump is a Unity 2D platformer. The player jumps across obstacles, collects coins, burgers and drinks, and survives with 5 lives. It has tilemap-based levels, a bird companion with a custom follow script, and a collectibles UI. It can be played on itch.io: samrah-niazi.itch.io/super-jump.

## Project: AI Code Mentor
@section projects
AI Code Mentor is a full-stack web application that uses TinyLlama, a small open-source language model run locally through Ollama, to analyze and explain Python code and spot bugs in real time, with speech synthesis. It has a Flask backend and an HTML, CSS and JavaScript front end that talks to it with fetch requests. Source code: github.com/Samrah-Niazi/AI_code_mentor.
